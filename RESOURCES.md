# Git-to-PR Resources

## Knowledge

- [Pro Git: Git Objects](https://git-scm.com/book/en/v2/Git-Internals-Git-Objects)
  Official Git book explanation of blobs, trees, and commit objects. Use for: understanding exactly what a commit stores.
- [Git revisions](https://git-scm.com/docs/gitrevisions)
  Official reference for commit reachability and two-dot/three-dot revision notation. Use for: understanding `git log base..head`.
- [git-diff](https://git-scm.com/docs/git-diff)
  Official command reference, including the special meaning of `git diff A...B`. Use for: understanding merge-base comparisons.
- [GitHub Docs: About pull requests](https://docs.github.com/en/pull-requests/get-started/about-pull-requests)
  Official overview separating PR conversation, commits, checks, and files changed. Use for: understanding what GitHub adds on top of Git.

## Wisdom (Communities)

- [Git mailing list](https://git-scm.com/community)
  Primary Git development community. Use for: subtle revision-selection or command-semantics questions not settled by the manual.
