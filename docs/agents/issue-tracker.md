# Issue tracker: GitHub

Issues and formal PRDs for this repository live in GitHub Issues. Use the `gh` CLI for operations.

## Repository

Infer the repository from the configured Git remote.

## Conventions

- Create issues with `gh issue create`.
- Read issues and comments with `gh issue view`.
- List and filter issues with `gh issue list`.
- Add comments with `gh issue comment`.
- Apply or remove labels with `gh issue edit`.
- Close issues with `gh issue close`.
- Use heredocs for multiline bodies.
- Resolve a bare `#<number>` as a PR first, then fall back to an issue.

## Pull requests as a request surface

PRs as a request surface: no.

## Skill integration

- "Publish to the issue tracker" means creating a GitHub issue.
- "Fetch the relevant ticket" means reading the issue and its comments.
- Formal PRDs and implementation tickets are published here.
