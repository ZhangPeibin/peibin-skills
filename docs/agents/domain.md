# Domain Docs

This repository uses a single domain context.

## Consumer rules

Before exploring the repository:

- Read `CONTEXT.md` when it exists.
- Read applicable ADRs under `docs/adr/`.
- Proceed silently when these files do not yet exist.
- Use terminology defined in `CONTEXT.md`.
- Surface conflicts with existing ADRs instead of silently overriding them.

## Layout

```text
/
|-- CONTEXT.md
`-- docs/
    `-- adr/
```
